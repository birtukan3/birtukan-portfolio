# Birtukan Getnet Portfolio

A responsive React portfolio built with Vite. The design uses the existing navy and teal identity and an optimized JPEG at `image/birtukan-portfolio.jpg`; the original photo at `image/birtukan.png` is preserved.

## Run locally

```sh
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build and preview

```sh
npm run build
npm run preview
```

Portfolio content, project details, contact links, and certificate entries are maintained in `src/App.jsx`; styling is in `src/styles.css`.
